# README как манифест открытых данных

**Type:** Micro Spec (документация) · **Effort:** 2 часа · **Date:** 2026-09-17 · **Owner:** Dex719

## What
Переписать `README.md`: проект — открытый, независимый от провайдеров набор данных о дорожной обстановке Алматы; сначала раздел для потребителей данных, затем для операторов сборщика.

## Why
Текущий README читается как инструкция к сборщику. Смысл проекта — накопленная, проверяемая, машиночитаемая история пробок и событий, которая принадлежит публике и не зависит от API, истории и условий 2ГИС/Яндекса: провайдеры показывают только «сейчас», а этот репозиторий хранит «всегда» в собственной схеме.

## How
- Новая структура: миссия и принципы независимости → как получить данные (git + Releases, примеры кода) → что внутри (схемы файлов) → как собирается (источники, интервалы, честность измерений) → свой сборщик (сервер / Actions) → эксплуатация (архивы, backup, безопасность) → участие (добавить источник) → лицензия.
- Сохранить все операционные контракты из прежнего README (семантика CSV/событий/карты, закрытие дня, backup/restore, cutover), сократив формулировки.
- Лицензия: файла `LICENSE` в репозитории нет — раздел фиксирует намерение (open data) и решение владельца (рекомендация: ODbL или CC BY 4.0 для данных, MIT для кода); файл лицензии не добавляется без решения владельца.

## Acceptance
README открывается разделом о миссии и способах получить данные без аккаунтов у провайдеров; операторские разделы сохранены; нет утраченных контрактов (сверка по списку разделов прежней версии); ссылки и команды корректны.

## Files
- `README.md` — полная переработка.

# Дополнение 2026-09-17: лицензии и правка README

**Type:** Micro Spec · **Effort:** 1 час

CC BY 4.0 — самый распространённый вариант для открытых городских данных: разрешает любое использование с указанием источника и не навязывает share-alike (в отличие от ODbL), MIT — стандарт для кода. Без файла лицензии данные формально не были открытыми.

## How
- `LICENSE` — чистый текст MIT (для распознавания GitHub), правообладатель `Dex719` (владелец может уточнить имя).
- `LICENSE-DATA.md` — область действия (git `data/`, релизы `data-*`, `staging`), условия CC BY 4.0, форма атрибуции, ссылка на legalcode, оговорки об условиях провайдеров, персональных данных и отсутствии гарантий.
- README: обновить раздел «Лицензия», добавить принцип «Открытая лицензия», добавить раздел «English summary».

## Acceptance
GitHub показывает лицензию MIT в шапке репозитория; README ссылается на оба файла; форма атрибуции приведена; английское описание объясняет, что это, как скачать и на каких условиях.
